Scoring notifications

Privacy and stored data

No passwords, Google cookies, browsing history, video URLs, or watch history are read or stored. No analytics, advertising, or developer server is used.

Only display preferences are saved by default. Sleeper username and league ID persist on this device only if you enable Remember setup. There is no Chrome account sync. The selected game and collapsed state last for the browser session. Public league and player records are cached temporarily in worker memory.

Sleeper receives requests for your username and league; ESPN receives NFL schedule requests. Both services receive normal connection metadata such as your IP address. Requests omit cookies and referrers.

The overlay intentionally displays team names and fantasy data on YouTube TV. It is visible on screen, including in screenshots and screen sharing; it is not a place to display secrets. Configuration is entered here on the extension's own page.

Clear all extension data removes saved setup, display preferences, session state and cached records. Existing requests may finish, but their results are discarded. Disabling or uninstalling the extension and reloading YouTube TV removes the overlay.
